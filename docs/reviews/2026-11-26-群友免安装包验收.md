## 已验收

- 最新工作树通过 TypeScript 类型检查、186 项前端单测、80 项引擎单测，以及公开、参赛、群友三版版本隔离检查。修正九模型测试的夹具，让它使用临时模型注册表并实际请求对齐，避免依赖本机保存的模型状态。
- 公开版组装目录和群友版 ZIP 都通过 `scripts/portable/verify.py`。群友版使用含中文和空格的新解压目录。运行验证使用包内 Python、Node、FFmpeg 和独立 PATH。
- 九个 ONNX 模型均在 CPU 上装载，VTL 使用 JD2/W02、实际合成音频。普通话与英语均实际使用 Whisper tiny 转写并用本地模型对齐。韵律、声道重合成和发声调音台模型入口通过。
- 实际导出 WAV、FLAC、MP3、M4A、发音卡 GIF/MP4、剪辑 MP4，以及包含 TextGrid 和声带 MP4 的单录音资料包。
- 全库音频归档处理完 308 项并从 HTTP 流完整下载。归档为 106,696,443 字节，CRC 复核通过。清单记录 276 条可用实录、32 条源库未提供的实录，以及 9 个独立颤音样例。
- 使用与项目不同的当前目录运行 `VoxFigura.cmd --no-browser`。独立 Edge 会话中，首页显示本地 VTL 就绪，国际音标表 Plus、剪辑时间线和群友版带署名选项的发音卡均可打开。控制台有一条 Three.js 重复加载警告和零错误。自动验收验证关闭启动器后其 Python 端口释放。
