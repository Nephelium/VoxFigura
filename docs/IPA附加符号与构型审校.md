# IPA 附加符号与构型审校

本文供标注方言、中古拟音和普通话窄式转写时查阅。范围是国际音标表 **Diacritics** 栏的 31 项。成对连接符、长短、重音、声调和非肺部气流记号在官方表中另列。字典可同时使用这些记号；声调作用于音节，连接符两边的部位标记可分属不同阶段。[国际语音学会正式表](https://www.internationalphoneticassociation.org/IPAcharts/IPA_charts_EI/IPA_charts_EI.html)

## 查表

| 记号 | 含义 | 例音 | 观察哪些器官、动作或时段 |
| --- | --- | --- | --- |
| ◌̥ | 清化 | n̥、d̥ | 目标音的声带振动减弱或消失。[n̥] 仍保留鼻腔通路，[d̥] 仍有口腔闭塞。清化可能只覆盖音段的一部分，单帧无法显示起止。下伸字母可用上置圆圈，如 [ŋ̊]。 |
| ◌̬ | 浊化 | s̬、t̬ | 构音部位保持，期间加入声带振动。[s̬] 仍需足够摩擦气流，[t̬] 的闭塞浊音可短于整个闭塞期。具体时程宜参照录音。 |
| ʰ | 送气 | tʰ、dʰ | 在典型塞音后出现声门开放和呼气噪声。塞音看除阻与起声的相对时间，塞擦音还需区分口腔摩擦与随后送气。浊送气的实现依语言而异。 |
| ◌̹ | 更圆唇 | ɔ̹ | 唇形相对基础元音更圆。可由收拢、前突或两者共同实现；保持舌位为参照，并按说话人标定唇形。 |
| ◌̜ | 较少圆唇 | ɔ̜ | 相对基础音减弱圆唇，仍可保留相当程度的圆唇。[ɔ̜] 与 [ʌ] 的关系取决于实际舌位、唇形和该语言的转写。 |
| ◌̟ | 偏前 | u̟、k̟ | 元音的舌体位置向前，舌面塞音的闭塞点向前。舌冠音要沿齿龈或腭面移动接触位置；唇前突不能一般地解释为构音部位偏前。 |
| ◌̠ | 偏后 | e̠、t̠ | 元音向元音空间后部移动；[t̠] 的舌冠闭塞比基准 [t] 靠后。单凭这个记号不能推出舌尖后卷。 |
| ◌̈ | 央化 | ë、ö | 前元音向后、后元音向前，偏向央元音区域。主要关注前后轴；两端的移动方向相反。 |
| ◌̽ | 向中央音质靠拢 | e̽、ɑ̽ | 目标朝 [ə] 所在的中部央区靠近，高低与前后都可能改变。低后元音可较高、较前，高前元音可较低、较后。 |
| ◌̩ | 成音节 | n̩、l̩ | 该音占据音节核。[n̩] 保持鼻通路，[l̩] 保持侧通路；关键在核位置和时序。不同语言允许的音节核不同。上置竖线亦可表示成音节。 |
| ◌̯ | 非音节性 | i̯、u̯ | 所标音段不独立占据一个音节核。双元音的非核部分仍有声道运动和时长；应随同一音节的轨迹处理。 |
| ˞ | r 音色 | ə˞、ɚ、a˞ | 标明 r 音色。普通话儿化可有舌尖上卷型或舌尖向下、舌体聚拢型；韵尾脱落、鼻化及音色变化由具体方言词项决定。可在个人套装中保存同一音标的实测构型。 |
| ◌̤ | 气声浊音 | a̤、b̤ | 声带振动伴较多漏气。[a̤] 可在元音核持续，[b̤] 需区分闭塞与除阻后气声的时序。声源轨与口腔轨分开处理。 |
| ◌̰ | 嘎裂声 | a̰、b̰ | 声带振动可呈紧缩、低频或不规则脉冲。不能由符号唯一指定 F0、抖动值或整段嘎裂的持续比例。 |
| ◌̼ | 舌唇音 | t̼、d̼ | 以舌尖或舌叶接触或逼近上唇。与舌冠齿音表面相似的图形仍须检查接触点在上唇还是上齿。 |
| ʷ | 唇化 | tʷ、kʷ | 主构音进行时叠加唇形收拢或圆唇，有些语言还伴随舌背动作。[kʷ] 应保留舌背闭塞，唇化起止由说话人和语境决定。 |
| ʲ | 腭化 | pʲ、tʲ、kʲ | 舌面趋近硬腭。[pʲ] 要维持双唇闭塞，[tʲ] 要保留舌冠主构音；[kʲ] 的主、次动作涉及同一舌体，可能产生部位前移。转写本身不规定独立的 [j] 段。 |
| ˠ | 软腭化 | lˠ、tˠ | 舌背趋近软腭，同时保留主构音。[lˠ] 还需侧向通路；只画舌背后隆不足以说明侧音已得到实现。 |
| ˤ | 咽化 | tˤ、sˤ | 咽腔增加收窄。闭塞或擦音的前部构音仍须维持，邻近元音还可能出现协同构音。实际收窄部位和时程需要个案证据。 |
| ◌̴ | 软腭化或咽化 | ɫ、l̴ | 横穿符号的波形给出宽泛的暗化转写。只凭 [ɫ] 不能唯一决定咽部和软腭各自的贡献，精细模拟时选录音构型或明确具体实现。 |
| ◌̝ | 偏高／收紧 | e̝、ɹ̝ | 元音 [e̝] 比基准 [e] 更闭；[ɹ̝] 则缩小主狭窄，可出现齿龈摩擦。两者都不要求提高音高或喉位。 |
| ◌̞ | 偏低／放宽 | e̞、β̞、ð̞ | 元音 [e̞] 更开；[β̞] 放宽双唇狭窄，[ð̞] 放宽舌与上齿之间的狭窄。后两者可形成近音，动作所用器官不同。 |
| ◌̘ | 舌根前伸 | e̘ | 舌根相对向前，常涉及咽腔容积变化。需要检查舌根与咽腔，单看舌面前后位置不够；声学效果随基础元音改变。 |
| ◌̙ | 舌根后缩 | e̙ | 舌根向后，常使咽部较窄。它与整个元音偏后、辅音咽化有不同的转写含义，实际生理动作可有重叠。 |
| ◌̪ | 齿部构音 | t̪、p̪ | [t̪] 以舌与牙齿构成闭塞；记在双唇塞音字母下的 [p̪] 可指下唇与上齿的闭塞。要同时识别主动和被动构音器。 |
| ◌̺ | 舌尖性 | t̺、s̺ | 指明舌尖参与主接触或狭窄。[t̺] 有闭塞，[s̺] 保留摩擦气流。该符号说明参与的舌部，对具体被动部位还要看基础音。 |
| ◌̻ | 舌叶性 | t̻、s̻ | 指明主接触或狭窄由舌叶形成。与舌尖性相比较，要观察接触面及气流通道；中矢状图不能单独显示完整横向接触面积。 |
| ◌̃ | 鼻化 | ã、ẽ | 口鼻声道耦合使本来以口腔为主的音带有鼻音色。对元音看软腭开度；对阻塞音要分别观察蓄压与鼻化时段。鼻化、鼻辅音和鼻除阻可分别标记。 |
| ⁿ | 鼻除阻 | dⁿ | 口腔仍有闭塞时开放腭咽通路，压力经鼻释放。与提前鼻化、独立后续 [n] 的区别依赖时序，静态口腔图只能呈现一个时刻。 |
| ˡ | 边除阻 | dˡ | 舌中线接触仍在时经舌侧释放。须观察横截面和释放时刻；它与另起一个独立的侧音音素具有不同的标注粒度。 |
| ◌̚ | 无可闻除阻 | t̚、k̚ | 听不到独立爆破。口腔可以稍后解除闭塞或与后一个闭塞重叠。标注可保留持阻段，不能仅凭听不到爆破推定实际除阻时刻。 |

“偏高、偏低”分别用 [e̝] 与 [e̞] 比较元音开口度，用 [ɹ̝] 与 [β̞] 比较辅音狭窄。测音高时应看 F0。儿化的形态与句中另一个独立的“儿”需要在字典中分别给出；西南官话一项对十位说话人的研究中，两种儿化央元音都出现舌体聚拢型。北方官话十八位说话人的超声数据中可见多种舌形。[北方官话实验](https://pubmed.ncbi.nlm.nih.gov/39279469/) · [西南官话实验](https://pubmed.ncbi.nlm.nih.gov/37934113/)

## 同形输入还涉及哪些记号

词典可用 ◌̋、◌́、◌̄、◌̀、◌̏ 表超高、高、中、低、超低平调。◌̌ 与 ◌̂ 表升、降，◌᷄ 与 ◌᷅ 表高升、低升，◌᷈ 表升降。调号附在元音或成音节辅音上，但其解释依整音节和语言的调类而定。网页读取这些调号时采用相对五度值；方言包的明确调类优先，同一轮廓可以配不同的实录 Hz 曲线。ꜜ、ꜛ 表后续调域降阶、升阶，↗、↘ 表整段语调趋势。当前没有从这些调域记号自动推算整句 F0。[官方声调及词重音表](https://www.internationalphoneticassociation.org/IPAcharts/common_files/pdfs/pdfs_IPA_charts_E/IPA_unitipa_T.pdf)

ˈ、ˌ 写在重读音节前，分别表示主要和次要重音。ː、ˑ、◌̆ 表长、半长、超短，具体毫秒数由材料决定。点号分音节，竖线划分较小或较大的韵律组，‿ 标示连接。上、下连接弧在塞擦音或双重构音上绑定相邻字母；上标 ʼ 指喷音，涉及非肺部气流。它们与鼻除阻 ⁿ、边除阻 ˡ 在音位切分和物理实现上各有区别。[官方总表](https://www.internationalphoneticassociation.org/IPAcharts/common_files/pdfs/pdfs_IPA_charts_E/IPA_unitipa.pdf)

## 网页如何生成构型

1. 区间保留输入音标。比较时做 Unicode 规范分解，处理清化上下置、成音节上下置、相对高低旁置记号和几个常见独立字形。连接符绑定两侧；音节边界终止前一音段。[Unicode 位置变体说明](https://www.unicode.org/L2/L2024/24080-ipa-diacritics-above.pdf)
2. 优先使用已选个人套装或默认录音的精确项。工厂查找首先匹配完整符号。JD2 在缺少精确项时可从相同基础音的 PTB 预设应用打包规则的局部几何差量；数据表含 107 个基础音，1,503 个非零的单项修饰。叠加多个记号是可编辑近似。带连接符的复合音保留各标记的归属，缺少逐阶段实录时静态视图只能显示参考形态。
3. 调类使用字典所属方言包。成音节、非音节性影响核的选择，清化和浊化影响有声标志。若计算模型缺少对应气流机制、次构音或除阻动作，文字标注仍可用于精细分析。非 JD2 说话人须用对应配置标定。研究用的验收应分别看边界、主要接触位置、气流通路和声学结果。
