## 1. 视觉定位与表面质感体系

### 1.1 整体视觉人格

VoxFigura 是一款面向高密度全屏桌面场景的**精密声学仪器与现代非线性剪辑台**。视觉设计遵循三条核心原则：
1. **数据与画布绝对优先**：界面框架必须退居声道剖面、瞬时声学图、国际音标矩阵、钢琴卷帘与舞台画面之后，杜绝喧宾夺主的厚重装饰。
2. **三区血统统一、质感微调**：知乎发音探索实验室、科研工作台与剪辑工作室共享同一套配色引擎、字号密度与基础控件几何，严禁做成割裂的拼接网页。
3. **主题色全域联动**：除固定物理/告警语义方向外，按钮主高亮、边框、选中态、活动控制点与默认波形线一律跟随用户选定的配色方案动态派生。

### 1.2 锁定默认基调：轻新拟态 × 科技磨砂光晕（`neumorphism-aurora`）

#### 四层科技感背景架构（解决纯白/纯黑平淡感）
底层非交互 `.tech-backdrop` 由四项材质叠加而成，并严格随当前 29 套 Codex 配色动态生成色调：
1. **动态多色弥散光球（Mesh Aurora Orbs）**：三枚大半径高模糊光球（取自当前主题的 `--accent`、`--teal`、`--violet`），日间模式透出温润珍珠彩晕，夜间模式呈现深邃空间极光，在 `@media (prefers-reduced-motion: reduce)` 下自动静止。
2. **径向渐隐坐标网格与声学同心弧**：极细 `32px × 32px` 工程坐标网格配合中央声学雷达圆弧，通过 `mask-image` 在边缘自然隐没，建立精密声学仪器纵深感。
3. **哑光微颗粒噪点（Micro Film Grain）**：叠加约 `3%–4%` 的 SVG `feTurbulence` 极细胶片颗粒，消除廉价塑料平滑感，呈现阳极氧化金属与磨砂玻璃质地。
4. **轻透明磨砂玻璃面板 + 轻新拟态双侧柔雕**：以 `src/styles/tokens.css` 为真源，主面板默认采用日间 `--glass-alpha: 68%` / 夜间 `--glass-alpha: 64%` 半透明底色（`defaultAppearance()` 运行时默认 `glassAlpha: 66`、`cardAlpha: 64`）配合 `backdrop-filter: blur(var(--glass-blur)) saturate(142%)`，默认模糊半径 `--glass-blur: 7px` 并提供 `0–22px` 实时模糊滑块（避免过度模糊把底图糊成一片），结合轻新拟态左上亮高光边与右下柔影，让底层纹理清晰透过面板；交互控件保留细腻微凸质感与内凹激活态。

#### 8 套表面质感与 12 档工作区背景
在全宽设置视图「外观与配色光效」分区保留以下切换能力，同时**科学画布（科研工作台剖面、`A(x)` / `H(f)` 曲线、多轨波形、M27 声道重建双图与舞台 16:9 画面）始终保持高对比锐利底板（`var(--panel)` 或舞台独立深色 Token）**；全站统一样式变量（`--border-w`、`--r-ctrl`、`--r-seg`、`--ctrl-bg`、`--ctrl-inset`）驱动按钮、胶囊与 `.vc-sel` 下拉浮层，禁止按钮渐变闪烁及暴露 OS 原生暗黑下拉菜单：
- **8 套可选表面质感（`BUILTIN_SKINS`，`data-style`）**：① **轻新拟态 × 磨砂玻璃（默认，`neumorphism`）**、② **轻黏土拟态（`clay`）**、③ **液态磨砂玻璃（`glass`）**、④ **精致仪器风（`minimal`）**、⑤ **现代材质分层 Material 3（`material`）**、⑥ **瑞士网格编排（`swiss`）**、⑦ **包豪斯几何（`bauhaus`）**、⑧ **轻新粗野（`brutal`）**。
- **工作区背景**。保留折光纸幕（默认）、潮汐海岸、叠色套印、岸边芦影、雾面底色。赭岩峡谷、苔林微光、霜岭长天、雨巷霓虹、月面环山、金釉拼砖和紫暮星环各有独立日间与夜间壁纸。支持独立调节模糊强度、背景饱和度、覆盖率和三路自定义色。注册表为 `BUILTIN_BACKDROPS`。
- **切换风格时的配色**。「当前配色」沿用已经选定的色板、背景和材质参数。「原始配色」应用按该风格示意卡取色的色板，并恢复默认底纹和材质参数。明暗与字体单独控制。
- **全屏展开层透底约定**：展开态 `6:4` 国际音标表 Plus、全宽独立设置视图、使用说明、关于/技术报告页与引用弹窗外围面板均透出底层 `.tech-backdrop` 质感。

## 2. 配色引擎与 Design Token 规范

### 2.1 完整复用 29+1 Codex 配色体系

前端样式层必须直接复用 `PhoneticToolbox_v3/frontend/src/design/themes.ts` 的 29 套预设配色与 1 套自定义单色派生引擎，不另造互不兼容的配色逻辑：

- **首次启动默认值**：主题 ID 为 `codex`（浅色 `#f9f9f9 / #202020 / #0969da`；深色 `#171717 / #ededed / #79aaff`），首次预览默认启动于 `Codex` 浅色（Web 正式版可跟随操作系统或由用户顶栏一键翻转明暗，并在设置页联动控制亮暗态预览）。
- **全量 29 套预设**：`absolutely`、`ayu`、`catppuccin`、`codex`、`dracula`、`everforest`、`github`、`gruvbox`、`linear`、`lobster`、`material`、`matrix`、`monokai`、`night-owl`、`nord`、`notion`、`og`、`oscurange`、`one`、`proof`、`raycast`、`rose-pine`、`sentry`、`solarized`、`temple`、`tokyo-night`、`vercel`、`vscode-plus`、`xcode`，另加 `custom` 自定义色。
- **对比度保底算法**：所有前景文字、次要文字、主高亮与语义辅助色必须通过 `readable(color, surfaces, minContrast)` 自动迭代调整——正文 `--text` 对所有底板维持 ≥ 7.0 对比度，次要文字 `--muted` 与高亮色 `--accent` 维持 ≥ 4.5 对比度。

### 2.2 核心基础 Token 表（由 `paletteTokens()` 动态生成）

| Token 名 | 语义用途 | 派生规则 / 约束 |
| --- | --- | --- |
| `--app` | 最底层应用壳、顶栏与底栏底色 | 取自主题 Seed 第 1 色 |
| `--panel` | 主工作区卡片、画布与属性面板底板 | `--app` 混入极微白色（深色 3.5%，浅色 5%） |
| `--sidebar` | 左侧导航与资产栏底色 | 与 `--app` 保持极轻层次差 |
| `--rail` | 窄图标栏与次级工具栏底色 | 避免刺眼高对比跳块 |
| `--border` | 1 px 面板与轨道分割线 | `--panel` 混入 20% 前景色 |
| `--text` | 主文字、图标与坐标系刻度 | 对比度 ≥ 7.0 |
| `--muted` | 次要标注、单位、快捷键提示与折叠说明 | 对比度 ≥ 4.5 |
| `--accent` | 主强调色（当前工作区、选中框、主按钮、活动控制点） | 源自主题 Seed 第 3 色并过可读性保底 |
| `--on-accent` | 叠加在 `--accent` 实心背景上的文字色 | 自动选取白或深黑中对比度更高者 |
| `--selected` | 选中行、激活标签、悬停底色 | `--panel` 混入 `--accent`（深色 16%，浅色 10%） |
| `--selection` | 时间轴框选与文本选区半透明遮罩 | `--accent` 带 13%–20% 透明度 |

### 3.3 窗口适配与全局自适应缩放规则

- **基于硬件逻辑分辨率的自适应密排（1080p 对齐 2560×1600 观感）**：
  - **`2560×1600`（QHD+ / HiDPI）及更高屏**：保持 `--page-scale: 1.00`（100% 原生锐利排版），依据 `screen.width * devicePixelRatio` 判断物理像素宽度（`physW > 2048` 时绝不二次缩小，避免 HiDPI 笔记本误触发过小字号）。
  - **`1920×1080` 标准桌面屏（`physW <= 2048 && vw <= 1960`）**：启动自动应用 **`--page-scale: 0.86`**（`86%` 自动缩放，映射出 `~2233×1256` 逻辑画布空间，使整体字号、圆角与控件密排观感与 `2560×1600` 笔记本屏幕保持一致）；`H(f)` 等物理图窗按同比例增高基底保证直观清晰。
  - **`1366×768` / 低分笔记本兼容（`vw < 1560`）**：自动应用 **`--page-scale: 0.80`** 并配合收紧侧栏（`206px` / `246px`），探索页主字标与音标（`.hero-word` / `.hero-ipa`）强制单行防折行，次级折叠组（VTL 其余 11 维与 `m27` 10 维）默认收起，严禁主视口溢出。
  - **手动覆写与一键复位**：设置页「外观与配色光效」提供 `70%–130%` 精细滑块与「自动」复位按钮，随时切换自动适配或自定义缩放。
- **全局分栏与全模块尺寸调节**：所有工作区与子视图的面板边界均铺设 6 px 隐藏可拖拽分割条（`.gutter-v` / `.gutter-h`，像素偏移按 `/ getCurrentPageScale()` 精确换算），用户可按需自由拉伸/收缩任一模块宽度或上下区高度，双击分割条原位复位，设置页提供「重置全部分栏比例」按钮；完整复用 `pageZoom.ts`（拦截浏览器 `Ctrl + 滚轮` 专供时间轴/画布缩放）。

## 6. 样式架构与图标技术约束

1. **禁止引入重型 UI 组件库**：严禁引入 Element Plus、Ant Design Vue、Naive UI 等自带厚重样式体系的框架，避免破坏 12 px / 27 px 极紧凑密度和 29+1 套动态配色一致性。

   - **已落地共享组件（`src/components/common/`）**：`IconSvg`、`CustomSelect`（`.vc-sel` + `#vcSelectMenu` 浮层）、`CompactSlider`、`SplitPane`、`VocalTractViewport`、`VoiceRenderSelect`、`SpeakerReferenceSelect`、`SpeakerReferenceControls`、`TopBar`、`ToastHost`、`TechBackdrop`、`NavArtwork`、`StartupSplash`、`StyleLabBackdoor`。
   - **规划中组件原语与现行 CSS 类替代（`src/styles/base.css`）**：
     - `SegmentedControl`（规划中）→ 现行替代：`.seg`、`.seg.control-seg`；
     - `FloatingPopover`（规划中）→ 现行替代：下拉浮层用 `CustomSelect` / `.vc-sel` + `#vcSelectMenu`，模态弹层用 `.export-modal-mask` + `.export-modal-card`（遮罩 `var(--overlay)`、层级 `var(--z-modal)`）；
