# 剪辑页本地目录与媒体库实施规划

**目标**　在剪辑页并排浏览本地文件和已导入素材，给媒体库腾出空间，并收窄节目监视器。

**实现方式**　沿用 Vue 组件、浏览器只读目录选择和现有素材导入链路。上方依次排列本地目录、媒体库、节目监视器和属性检查器，底部保留全宽时间轴。与现有的单栏切换相比，并排布局可直接将目录文件拖入媒体库，也能在定位下一个文件时继续查看工程素材。

## 1. 拆分面板并接通目录操作

- 在 `src/components/studio/StudioStageView.vue` 拆出本地目录，在 `src/data/splitter-layout.ts` 登记分栏宽度。目录和媒体库可独立调整，监视画面保持 16:9。
- 在 `src/components/studio/StudioDirectoryBrowser.vue` 保留子目录和搜索。单击选中文件，双击或按 Enter 导入，也可用导入所选按钮。目录文件可拖入媒体库，匹配轨道类型时也可拖入时间轴。
- 沿用系统文件选择器和兼容目录选择入口。媒体库的独立导入、搜索和外部文件拖放继续可用，打开目录时媒体库仍可操作。

## 2. 增加素材视图与预览

- 默认使用多列小图，按媒体库宽度重排。另提供每行一个文件名的紧凑列表，两种视图保留相同的筛选、选中和拖放操作。
- 使用原图预览图片和受支持的动图，视频进入可见区域后提取静态帧。音频复用已有波形，有待重新关联或无法预览的文件显示类型图标。

## 3. 验收

- 执行 `npm run typecheck`、`npm test`、`npm run build` 和 `npm run build:hackathon`。
- 用本地图片、动图、视频和音频验证目录浏览、选择、导入、跨面板拖放、时间轴拖放和视图切换。检查桌面布局、监视器比例、列宽调整和窄窗口横向滚动。
