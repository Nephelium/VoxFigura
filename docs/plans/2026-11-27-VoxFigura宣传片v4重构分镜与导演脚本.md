# VoxFigura 宣传片 v4 重构分镜与导演脚本

> 版本：v4.0（彻底重构版） · 基准画幅：`1920×1080` · 帧率：`30 fps` · 总时长：约 `122.3 s`（`3670` 帧）
> 核心美学：亮色日间工作台为主（约 80% 亮色 + 20% 精选暗色反差），浮动桌面窗口构图，大号高辨识矢量鼠标全程交互，无框编辑排版直出字卡，严格零漂移音画同步。

## 1. 全局设计规范与红线清单

1. **主题比例与色系弧线**：
   - 绝对禁止以深夜红色开场；暗色 `瑞士网格 · 珊瑚朱砂` 全片仅在 **S08 发声调音台** 出现 1 次。
   - 多主题日夜切换通过 `window.__VC_STYLE__` 执行：
     - 开场与声学核心（S01–S07）：`轻新拟态·原始` 日间、`轻新粗野·原始` 日间、`轻黏土·陶土暖白` 日间、`极简仪器·校样宣纸` 日间。
     - 发声调音台单人对比（S08）：`瑞士网格·珊瑚朱砂` 夜间（全片唯一暗红时刻）。
     - 双人变身、字典、连续统、发音卡（S09–S12）：迅速切回 `轻新粗野·原始` 日间、`极简仪器·校样宣纸` 日间、`液态磨砂·原始` 日间、`包豪斯·原始` 日间。
     - 声乐编曲与多轨剪辑（S13–S15）：`轻新粗野·原始` 夜间配冰川星空视觉，形成呼吸反差。
     - 收尾合影（S16）：切回亮色瓷白（`LOOKS.porcelain`）发布会合影。
2. **构图与排版原则**：
   - 放弃原软件铺满全屏与半透明黑底圆角大框；所有产品界面置于 `1620px` 宽圆角浮动窗口中，底部配 `video-shotcraft` `<Stage>` 亮白/暖纸/夜蓝质感画布与微颗粒。
   - 标题与说明采用浮窗上方无框编辑眉题+主标题，搭配 `PaperTitleCard`、`TitleDemoteToLabel`、`MarkerUnderlineTitle`、`BlurSlide` 等无框动效字卡。
3. **术语与资产约束**：
   - 全片统一使用 **`严式记音`**，严禁出现“窄标”字样；严禁单拎“双音调嗓音”作标题或主卖点。
   - 全部模型均用官方命名：`Vox2Tract-Lite`、`Tract2Vox-Lite`、`Vox2Spk-Lite`、`IPA2Tract-Lite`、`Text2Prosody-Lite`、`Tract2Area-Proxy`、`DPDFNet`、`SwiftF0`、`Vox2Align-Lite v2`。
   - 仅使用 `public/icons/` 下与当前色系一致的正式图标，禁止使用旧版黄紫图标与 UI Emoji。
4. **同步与交互铁律**：
   - 所有动态界面通过真实 30fps 视频录制 + 注入式大号 SVG 矢量鼠标与点击涟漪采集，杜绝静态截图假播。
   - 音画播放起点由时间戳与帧差分校验锁定，误差控制在 ±1 帧以内。

## 3. 声音设计与混音架构

- **配乐替换**：彻底弃用旧版节奏配乐，从 Freesound 选用明亮、富有推进力的现代电子/钢琴律动配乐，并保留一条无配乐纯人声+物理拟音验收版（`{"bgm":false}`）。
- **物理拟音（Freesound CC0）**：采用微风切入（`whoosh-micro`）、机械微动双点击交替（`click-a` / `click-b` 防机枪感）、纸张滑入（`paper-slide`）、落印低冲（`impact-thud`）、轻量起势（`riser-subtle`）与玻璃微鸣（`glass-ping`），做 `-1` 帧 AAC 编码前导补偿。
- **动态压低（Ducking）**：所有原声、音标、合成、调音、连续统与演唱段落配乐平顺下潜至 `-15 dB`，字卡与无原声过场抬升至 `-5.5 dB`，输出峰值限幅于 `-1.0 dBFS` 以内。
