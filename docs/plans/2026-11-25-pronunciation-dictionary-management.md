# 发音字典管理实施规划

## 目标

在同一页管理语音合成和编曲使用的发音字典，同时保留现有方言采录、调型手绘和变调试算。界面名称改为「发音字典管理」，内部仍用现有的工作区标识，以便恢复已保存的布局和导航状态。

## 四栏布局

| 栏位 | 内容 | 主要操作 |
| --- | --- | --- |
| 字典库 | 个人发音字典、汉语转写、英语 CMUdict、日语词典、内置与自建方言字典 | 切换、创建、复制、导入。标示当前用于语音合成和编曲的个人字典 |
| 词条列表 | 当前字典的字词、IPA、来源或调类。长词显示结构化音节，列表分页 | 按字词、IPA 或备注查找，选择词条 |
| 词条编辑 | 所选词条和要编辑的音节。显示原读音、保存目标、作用范围 | 编辑、添加、复制词条、删除词条。预览同音节数量后一次提交 |
| 字典工具 | 当前字典的管理操作和就地指引。方言字典显示调型、变调、采录工具 | 使用、重命名、复制、删除、导出。方言可选择构型套装、采录、试听、写入主轨 |

沿用项目面板、控件、文字和颜色 token。四栏从左到右依次是来源、浏览、编辑和工具，词表与方言工具分配弹性空间。窄视口保留完整操作并允许项目约定的滚动；表单按钮可以换行，列表和工具独立滚动。使用现有图标与声学图表组件。

## 字典和修改范围

- 个人字典直接读写现有个人词典簿。新建、重命名、整本复制、切换为当前字典、导入导出和删除都在字典库内完成。支持明确确认后删除，删除正在使用的一本时回落到其他个人字典，始终留一本可用的本地字典。
- 内置汉语、英语和日语提供查询和可编辑副本，直接修改时写入当前个人字典。副本继承离线基线并独立存储增改，可以切换到「个人词条」管理覆盖读音。汉语按转写标准、英语按原词和音节位置、日语按假名或 MFA 词和拍位定位。
- 内置方言预设可完整复制成可编辑方言字典。自建方言字典可新建、复制、修改、重命名、导入导出及确认删除。继续使用原方言包格式，带上词条、调类、变调规则、构型引用及已维护的参考调域。
- 变调规则编辑和试算只在方言字典提供。普通话与英语保留 Text2Prosody-Lite 韵律模型，默认关掉模型前置的显式变调规则。日语延用内置假名和 MFA 词典读音处理。
- 「仅此词条」只更新所选音节所在的那一条。「同音节」在当前字典内匹配相同的完整音素序列，匹配时忽略声调和重音，保留各条原有声调、重音和备注。空格、点等只作为原格式支持的音节边界，禁止对子串做全局替换。批量修改先显示实际匹配数量，保留词条级元数据。音素改变后，保留仍适用的时长和构型数据，重新合成时为已替换音素使用当前构型。
- 保留两类本地存储键、既有条目键和导出版本。字典或批量词条更新采用单次写入，失败时保持显示与已保存数据一致。没有数据迁移。

## 实施顺序

1. **字典操作与音节编辑规则。** 在 src/data/user-lexicon.ts 和 src/data/dialect-user-library.ts 增加可验证的字典 CRUD 和单次批量提交。补充 src/data/pronunciation-dictionaries.ts，统一发音列表与写入映射，并从 packages/g2p-ts 复用字词、音素和拍位资料。验证同音节匹配、转写标准隔离、多音节边界、旧词典和失败原子性。
2. **新页面与导航。** 新建 src/components/research/PronunciationDictionaryView.vue 和相应词条交互，接入 ResearchWorkbenchView.vue。将 DialectStudioView.vue 缩为可嵌入工具区，从词条列移除原调型工具中的重复词表，保留采录、绘图、沙盒、试听和写入主轨。同步导航、帮助和尺寸设置文案。
3. **读回与导入导出。** 通过现有个人字典和方言库接入语音合成、编曲。对旧版个人 JSON、方言 JSON、CSV 和 TSV 验证导入。方言导入成为可独立保存的本地字典，工作区切换不会覆盖另一份字典。
4. **验收。** 运行 npm run typecheck、npm test、Python 引擎单测、npm run build 和 npm run build:hackathon。在浏览器验证四栏、深浅主题、字典复制和删除、单条与批量 IPA 修改、刷新后持久化、重新编译入轨，以及方言工具切换。结果记录在本规划末尾。

## 验收记录

- 类型检查通过。前端与 TypeScript 内核 131 项测试通过，Python 引擎 77 项测试通过。公开版和参赛版均通过本地构建及版本隔离校验。
- 在参赛版浏览器验证了 2560×1600 浅色布局与 1120×700 深色布局。16:10 窗口内完整显示四栏。
- 在独立浏览器会话验证个人字典和词条的新增、重命名、复制、确认删除与刷新读回。批量修改匹配到指定的两个同音节，保留各自调值。同一个字典的结果可在语音合成和编曲读回。
- 验证粤语字典复制、方言 JSON 导出再导入、TSV 列映射、CMUdict 副本及不同音节数的英语读音切换。检查了日语 MFA 词条的查找与拍位编辑入口。
- 方言工具保留调型、变调试算和采录入口。普通话调型预设隐藏并跳过显式变调规则。浏览器调用本地 Text2Prosody-Lite 时带有 tone_sandhi: false，并获得成功预测。日语 MFA 数据提供读音、拍位与概率。
- 本轮采录验收覆盖入口和切换，实际麦克风录音与试听须在有声环境确认。

## 四栏排版调整

- 默认目录显示北京官话宽式、黄伯荣和廖序东《现代汉语》、赵元任《汉语口语语法》、UntPhesoca 宽式、英语 CMUdict、标准假名和日语 MFA，方言示例保留广州粤语。已有个人字典和自建方言字典继续在各自分组中显示。
- 三条分隔线分别调整相邻两栏，沿用项目的拖动、键盘、双击复位和会话尺寸设置。方言词条和连读变调规则在第三栏切换。右栏调型面板随工具栏换行增高，上方为赵氏五度，下方为合成基频。
- 已用 15px 字号在 2560×1398 和 1120×700 验证分栏与控件间距，实测三条分隔线拖动、刷新恢复、双击复位、词条草稿切换和方言副本规则保存。
- 四列的位置与默认宽度由 CSS 定义，拖动只更新列宽变量。去掉动态栏宽并模拟旧页面缺少分隔线时，四列仍在同一行。已分别检查开发页热更新和两版构建预览。
