## 一、核心创作铁律（反抽搐 · 反廉价 · 强因果）

1. **逻辑先于花哨，零无故抽搐**：严禁 5–7 帧无意义闪切、伪手持抖动、全屏狂震与高频卡点轰炸。每个镜头具备清晰的**动作起点 → 视觉结果 → 静止停留（hold ≥ 1.0 秒）**因果链；所有缩放与平移使用减速曲线（`cubic-bezier` 急起缓落），绝不使用往复抖动。
2. **真软件 2× 高清实录，零假 UI 拼图**：全片界面均来自运行中的 VoxFigura 真实桌面工作台（1920×1080 窗口，2 倍像素比截帧/录屏），局部放大通过高分辨率源画面与 CSS `zoom` 重栅格化实现，保证汉字、IPA 音标、语谱图刻度与按钮字迹锐利如印刷品。
3. **真实合成声音为主角，彻底杜绝廉价电子音效**：凡演示语音合成、发声调音台、音色变身、彩蛋工程、连续统与声乐编曲，优先播放 VoxFigura 引擎真实生成的 `Tract2Vox-Lite` 神经语音或物理声管结果。严禁使用游戏提示音、合成器哔哔声或电子脉冲声；仅在关键转场与落位节点配低音量物理拟音（微弱纸张翻页、镜头推进气流感、干脆机械落锁），音量压在 `-18` 至 `-22 dBFS`。
4. **BGM 饱满律动、让位人声**：主配乐采用现代器乐律动铺底（如 `house-vibez` 级别清晰底鼓与温暖和声），无语音镜头稳态在 `-15` 至 `-16 dBFS`，出现真实合成语音或歌声时用侧链平滑下压 5–6 dB，词尾结束后柔和回弹。
5. **官方模型命名与零 Emoji 规范**：全片文案、字幕与角标严格使用官方模型名 `Vox2Tract-Lite`、`Tract2Vox-Lite`、`Vox2Spk-Lite`、`IPA2Tract-Lite`、`DPDFNet`、`Text2Prosody-Lite`、`Tract2Area-Proxy`、`SwiftF0`、`Vox2Align-Lite v2` 及按需本地 `SenseVoice-Small`，界面与字幕全程零 Emoji。
