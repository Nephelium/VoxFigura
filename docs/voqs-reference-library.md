# VoQS 实录声门库

23 条可用录音覆盖 14 种发声类型及参照。M27 在 CPU 上以 50 Hz 提取 10 维声门轨迹，气压使用 Pa。VoQS 仅登记发声标签和可用的声段起止时间。独立缓存 `voqs/` 保存声门参数，音素构型库保留 IPA 录音。程序保留此前生成的原缓存，当前 IPA 查询不会使用旧 VoQS 口腔轮廓。

有声段标记时，在标记内部收窄采样范围。主录音工程的九条选中麦克风轨缺少配套标记，使用录音能量筛选有效区间。各维按模型支持范围归一化，在有效区间内选择距离中位数向量最近的一帧。`voqs-recordings.json` 保留录音编号和具体帧号，复制到锚点的是该帧的实际估计值。

- 压紧、振动与漏气组依次排列紧声 `V͈`、常态浊声 `V`、气声 `V̤`、耳语浊声 `Ṿ`、纯耳语 `W`。
- 不规则振动与假声分别成组。同组排序表示发声机制的邻近关系，组合音质跨越多个维度。
- `vq_08_pressed_a` 对应紧声 `V͈`。`vq_11_raised_larynx_a` 与 `vq_12_lowered_larynx_a` 分别对应喉位偏高 `L̝` 和偏低 `L̞`。两条记录可写入独立的 VTL 喉位控制，初值为 +0.5 cm 和 −0.5 cm，可以调整。这两个数值是合成控制量。录音反演的声门十维不估计喉位位移。

录音数据保存在本机。标注和剪辑会直接使用锚点记录的声门控制和压力，音符和独立基频轨仍决定合成基频。锚点参数保持到下一点。当前运行环境中没有可接入的专用 VoQS 点间过渡模型。

VoQS 实录按反演控制轨驱动所选 VTL 说话人的原生声门模型和固定 [ə] 管腔。嘎裂类实录的专用入口使用 40 Hz 的原生 F0 下限，常规 VTL 控制入口的下限为 60 Hz。超出合成范围及缺失的帧在重合成中留静音。控制轨每秒 50 帧，图中保留原反演估计。
