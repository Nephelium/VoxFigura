# IPA 录音与声道构型核查

## 数据和复现

目录共登记 307 条。238 条来自桌面 `国际音标/IPA` 的正式 WAV 导出，28 条来自 `国际音标/补充`，9 条从桌面 IPA 录音工程的已选版本按既有剪辑区间读取麦克风声道，32 条没有可用录音。40 条有录音的内爆音、喷音和啧音保留试听。212 条生成 IPA 声道轨迹并纳入调音部位筛查。23 条 VoQS 录音归入[实录声门库](voqs-reference-library.md)。默认只读套装选取正式 Phones 标注中目标音中央的实算帧。构型和个人录音由本机服务读取，音频不随前端构建分发。

在本工程根目录运行以下命令。第一项只读源工程，把派生媒体、轨迹和构型索引写入本工程 `.cache/ipa-references/`。第二项以原生 JD2 重新求解声道截面。两个命令均可重复执行。

```powershell
& 'F:/TensorTract3_Train/.venv/Scripts/python.exe' -B scripts/prepare_ipa_references.py
& 'F:/TensorTract3_Train/.venv/Scripts/python.exe' -B scripts/audit_ipa_constrictions.py
```

[录音全量目录](ipa-reference-inventory.csv)记录录音、轨迹、原标注区间和复核线索。`main-T148` 的两个标注区间之外分别有持续高能量，位于 0.59–0.75 s 和 1.27–1.43 s。另有 8 条正式 TextGrid 与自动保存版本不同。原有边界、标签和音频保留原状。

## 调音部位

[212 条录音的部位筛查](ipa-constriction-audit.csv)逐条给出任务预期的调音部位、可判定的粗分区和模型主收窄截面的坐标。以半开 TextGrid 目标音区间内的 50 Hz 控制帧重算原生 JD2 截面。100 ms 及以上的区间各去头尾 15%，以降低相邻音共构的影响。每帧在口咽道中选择截面积最小的点，并记录相应的正中间隙。粗分区使用截面坐标，参考本机 JD2 内置 `/p t k q/` 构型的收窄位置。靠近分界的截面和不同实例之间不稳定的结果保留待定。

疑似偏位要求同一录音的所有标注实例均符合以下条件。至少三个有效帧中有 70% 落在同一粗区，主收窄截面距分区边界超过 0.22 cm，面积中位数不超过 0.35 cm²，正中间隙中位数不超过 0.60 cm，期望区最窄截面的面积达到 0.50 cm² 且至少是主收窄截面的两倍。缺目标标注时，仅描述录音中央部分。元音、VoQS、侧向气流及正中切面难以判定的复杂接触关系保留待定。

46 条与期望粗分区相符，164 条待定。两条达到疑似偏位条件。

| 录音 | 任务预期 | 两个实例的模型主收窄 |
| --- | --- | --- |
| `main-T111` `[ʁ]` | 小舌 | 前口腔冠部，x 约 4.86 和 4.92 cm，面积约 0.097 和 0.149 cm² |
| `main-T130` `[ð̞]` | 齿 | 唇区，x 约 5.74 和 5.94 cm，面积约 0.239 和 0.310 cm² |

这两条记录仍需结合动态轮廓回听复核。
